# 발표 자료 후보

최종 발표(12/9)에 쓸 캡처·로그·도식을 모으는 색인이다. 캡처를 올릴 때 한 줄씩 추가하면 발표 준비 때 슬라이드 순서대로 옮기기만 하면 된다.

**규칙**　민감값을 가린 사본(`*-masked.png`)만 링크한다. 슬라이드 설명은 “무엇을 했다”가 아니라 **“이 화면이 무엇을 증명하는가”**로 쓴다.
