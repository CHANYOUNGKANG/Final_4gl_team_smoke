서비스

네 가지 일을 한 팀이 한 흐름으로

망 분리, 서버 정비, 클라우드 이전, 배포 자동화는 서로의 결과를 넘겨받아야 끝납니다. 각 단계에서 확인한 결과를 다음 단계의 시작 조건으로 씁니다.

SMOKE NET 보안 네트워크 재구축

업무망·관리망·서비스망이 한 대역이면 웹 서버 침입이 어디까지 번졌는지 알 수 없습니다.

바꾸는 것
VLAN 분리, 경계 라우터·방화벽·코어 스위치 이중화, 지사는 IPsec VPN으로 서비스망에만 연결
쓰는 기술
GNS3, Cisco IOSv·ASA, pfSense, BGP·OSPF·HSRP, Snort
완료 기준
업무 PC에서 관리 포트 접근 차단, 장비 한 대를 끊어도 통신 복구 기록
담당 이준호

SMOKE OPS 서버 정비와 운영 알림

계정과 SSH 설정이 제각각이고 로그가 서버마다 흩어져 있으면 사고가 나도 경로를 따라갈 수 없습니다.

바꾸는 것
계정·SSH 키 인증·로그·백업 정비, 이관 원본의 게시글 건수와 파일 해시 목록, 알림 메일 통합
쓰는 기술
Rocky Linux, MariaDB, NFS, rsyslog, Postfix·Roundcube, Ansible
완료 기준
원본 해시 목록, IDS·백업·장애·배포 알림의 수신 기록
담당 이우빈

SMOKE MOVE AWS 이전

첨부파일이 늘어 디스크가 부족하고, 서버 한 대가 멈추면 공지도 함께 멈추던 구조를 바꿉니다.

바꾸는 것
두 가용 영역의 EKS, HTTPS ALB, 게시글은 사설 RDS, 첨부는 비공개 S3·CloudFront
쓰는 기술
VPC, EKS, ALB·ACM, Route 53, RDS, S3, EFS, ElastiCache, CloudWatch
완료 기준
이관 전후 글 건수·본문·파일 해시 일치, 워커 한 대를 내려도 조회 유지
담당 강찬영

SMOKE SHIFT 무중단 배포

새 버전을 올릴 때마다 Tomcat을 재시작하면, 고객이 읽던 공지가 그 순간 끊깁니다.

바꾸는 것
Git 반영 → Jenkins 테스트·이미지 빌드 → Green 배포·검사 → ALB 전환, 실패하면 Blue로 자동 복귀
쓰는 기술
GitHub, Jenkins, Maven, Docker, ECR, Ansible, Kubernetes
완료 기준
커밋·빌드·이미지 태그가 한 줄로 이어지고, 배포 중 조회 실패 0건

해든정밀㈜ 공지·자료실 이전

고객사와 협력사에 납품 일정, 품질 인증서, 도면을 배포하는 정밀 가공 부품 제조사입니다. 기존 글과 파일을 하나도 잃지 않고, 배포 중에도 조회가 끊기지 않는 것이 의뢰 조건이었습니다.
