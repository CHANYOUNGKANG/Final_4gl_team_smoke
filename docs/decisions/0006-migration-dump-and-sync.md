# ADR-0006: 이관은 mysqldump·Bastion·RDS와 `aws s3 sync`로 하고 해시로 대조한다

- **상태**: 제안
- **날짜**: 2026-11-25
- **담당**: 이준호 · 이우빈

## 상황

고객 조건 “기존 공지와 첨부파일 보존”. RDS는 사설 데이터 서브넷에 있어 밖에서 바로 접속할 수 없다. 첨부파일은 NFS에 있다.

## 검토한 선택지

| 선택지 | 장점 | 단점 |
| --- | --- | --- |
| AWS DMS | 지속 복제 | 복제 인스턴스 시간당 과금, 실습 규모에 과함 |
| **mysqldump → scp(Bastion) → mysql 복원** | 단순, 절차를 그대로 시연 | 최종 이관 때 쓰기 중지 필요 |
| **첨부는 `aws s3 sync`** | 끊겨도 빠진 파일만 재전송 | 업로드 전용 IAM 권한 관리 |

## 결정

쓰기를 잠시 멈춘 뒤 덤프와 첨부를 옮기고, 게시글 건수·대표 본문·파일별 SHA-256이 모두 같을 때만 서비스 주소를 전환한다.

## 결과

- 좋아지는 것: 무결성을 숫자로 증명(NFR-03).
- 감수하는 것: 최종 이관 중 짧은 쓰기 중지.
- 확인 방법: [이관 대조표](../templates/aws/migration-compare.md), 결과 기록표 “데이터 이관”.
