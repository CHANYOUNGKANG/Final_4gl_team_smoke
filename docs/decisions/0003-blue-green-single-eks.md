# ADR-0003: 블루그린은 EKS 클러스터 하나와 ALB 대상 그룹 2개로 한다

- **상태**: 제안
- **날짜**: 2026-11-25
- **담당**: 강찬영 · 이우빈

## 상황

고객 조건 “배포 중에도 자료 조회 가능”을 만족해야 한다. 실습 예산이 작아 클러스터를 두 개 운영하기 어렵다.

## 검토한 선택지

| 선택지 | 장점 | 단점 |
| --- | --- | --- |
| 롤링 업데이트 | 자원 추가 거의 없음 | 섞인 버전 구간, 즉시 되돌리기 어려움 |
| 클러스터 2개(Blue·Green) | 격리 최고 | EKS 컨트롤 플레인·워커 비용 2배 |
| **클러스터 1개 + Deployment 2벌 + ALB 대상 그룹 2개** | 전환·복귀가 리스너 규칙 변경 한 번 | 관찰 시간 동안 Pod 2벌 용량 필요 |

## 결정

Blue·Green을 같은 EKS의 Deployment·Service 두 벌로 띄우고, ALB 리스너가 가리키는 대상 그룹만 바꾼다. Green 전용 경로에서 글 작성·조회가 성공해야 전환하고, 전환 후 운영 주소 검사가 실패하면 Blue로 되돌린다.

## 결과

- 좋아지는 것: 재배포 없이 복귀, 사용자 요청은 끊기지 않는다.
- 감수하는 것: 겹치는 시간의 워커 용량·비용(NFR-07에 기록).
- 확인 방법: 결과 기록표 “정상 배포 / 전환 전 차단 / 전환 후 자동 롤백”, 조회 실패 0건 목표.
