# 운영 런북 (장애 대응 절차)

[요구사항 NFR-06 운영성](../requirements/README.md#비기능-요구사항) · [양식](runbook-template.md) · [설계 결정](../decisions/README.md)

고객 운영팀에 넘길 대응 절차다. 알림 메일 한 통을 받았을 때 **무엇을 보고, 무엇을 하고, 어떻게 끝났는지 확인하는지**를 순서대로 적는다. 시연 때 한 번씩 그대로 따라 해 보고, 걸린 시간과 막힌 곳을 고친다.

| 런북 | 시작 조건 (알림) | 담당 | 상태 |
| --- | --- | --- | --- |
| [배포 실패 · 자동 롤백 확인](deploy-rollback.md) | `[배포] 실패 · 롤백` | 강찬영 | 초안 · 미검증 |
| [워커 노드 장애](worker-failure.md) | `[장애] smoke-worker-down` | 이우빈 | 초안 · 미검증 |
| [운영 알림이 오지 않음](alerts-missing.md) | 시험 알람 후 1분 내 미수신 | 이준호 | 초안 · 미검증 |

**규칙**　명령에 비밀값·실제 주소를 넣지 않는다(`DEPLOY_HOST` 같은 변수). 시연으로 검증하면 상태를 `검증 MM/DD`로 바꾸고 걸린 시간을 적는다.
