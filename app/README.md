# 공지 웹앱 인계표

[서버 담당](../server/README.md) · [CI/CD 담당](../cicd/README.md) · [첫날 작업표](../docs/delivery/README.md#첫날-작업표)

이준호가 기존 공지 앱의 실행 정보를 채우고, 강찬영이 같은 버전으로 Jenkins에서 첫 빌드를 확인한다. 소스를 이 저장소에 옮기면 이 폴더에 두고, 기존 저장소에서 관리하면 아래에 저장소 주소와 커밋을 적는다.

| 항목 | 팀 확인값 |
| --- | --- |
| 소스 위치 · 기준 브랜치 또는 커밋 SHA | 확인 대기 |
| Java · Tomcat 버전 | 확인 대기 |
| Maven 빌드 위치 · WAR 파일명 | 확인 대기 |
| 공지 조회 경로 · 정상 응답에서 확인할 내용 | 확인 대기 |
| 테스트 공지 작성·조회 방법 | 확인 대기 |
| 필요한 환경 변수 이름 · 설정 주입 위치 | 확인 대기 |

첫 빌드의 완료 기준은 원본 커밋, Jenkins 테스트 결과, 생성된 WAR 경로를 한 실행에서 대조할 수 있는 것이다.
